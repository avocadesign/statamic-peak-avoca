## Page builder blocks

### Text (`text`)

A heading, an optional subheading and a short passage of text.

Listed under Content in the page builder.

This block's content can include the text editor sets listed under Text editor sets.

#### When to use

- A short introduction or explanation, from a sentence or two up to a few short paragraphs.
- Short text that needs a link, a list or a button.
- Set Display style to Offset to put a short heading beside the text, or to Centre for a short statement that should stand out.

#### When not to use

- A longer story on a page builder page: break it into multiple blocks with mixed blocks types, such as Media and text or Cards.
- Text that belongs beside one image or video: use Media and text.
- Two short pieces of text side by side: use Text Columns.
- A short prompt to act, with a button: use Call to action.
- Several short items of equal weight: use Cards.
- Long, continuous text such as a policy, terms or an article: use a "simple" page or post instead.

#### Notes for AI

- Keep the content short: no more than three short paragraphs, about 150 words in total.
- Do not put headings inside the content. If the text needs subheadings, it is too long for this block.
- Keep the heading to one line and the subheading to one sentence, or leave the subheading empty.
- Use Offset only with a heading of a few words, because the heading sits in a narrow column.
- Use Centre all text only for a sentence or two, because centred paragraphs are hard to read.

### Media and text (`media_and_text`)

An image or video beside a heading, short text and optional buttons.

Listed under Content in the page builder.

This block's content can include the text editor sets listed under Text editor sets.

#### When to use

- Explaining something an image or video helps show, such as a service, a product or a place.
- Introducing a topic with a strong photo, a short paragraph and a link or button.
- A run of features down a page: switch Media position between Left and Right from one block to the next.
- Set Column layout to Edge to center for a photo that runs to the edge of the screen, or to Text above media for a wide image or video that needs the full width.

#### When not to use

- Text with no image or video: use Text.
- Several images of equal weight: use Two Images or Gallery.
- Several short items, each with its own image: use Cards.
- Long text: the column beside the media is narrow, so the text runs far below the image. Use a "simple" page or post instead.
- A short prompt to act with no media: use Call to action.

#### Notes for AI

- Keep the text short: a heading, an optional one-sentence subheading and no more than 150 words of content.
- Use one button, or two at most.
- Always give the image alt text.
- Check the image's Crop options and choose the one that helps the image fit the content beside it: Portrait or Square when the text runs taller than the image, Landscape or Video when the text is short. No Crop keeps the whole image.
- For a video, use a YouTube or Vimeo address.
- When Media and text blocks follow each other, alternate Media position.
- Left col narrow and Right col narrow make that side a third of the width. Put the image in the narrow column only when it is small, such as a portrait or a logo.
- On phones the media always shows above the text, whatever Media position is set to.

### Text Columns (`columns`)

A heading, an optional subheading and two columns side by side, each holding text and elements such as images, tables, pull quotes or buttons.

Listed under Content in the page builder.

This block's content can include the text editor sets listed under Text editor sets.

#### When to use

- Content that reads well in two parts, such as a service and what it includes, or a description beside a table of prices.
- Longer content that benefits from being split across two columns, with subheadings, lists and links.
- Mixing text with other elements: each column can hold images, videos, tables, pull quotes, buttons, contact details and more.
- Set Column Width to Left col narrow or Right col narrow when one column holds a summary or a small element and the other holds the main content.
- To label the block in the editor without showing a heading on the page, write a heading and switch on Hide headings.

#### When not to use

- A short passage in one column: use Text.
- One image or video beside short text, where the image should lead: use Media and text.
- Three or more short items of equal weight: use Cards.
- Long, continuous text such as a policy, terms or an article: use a "simple" page or post instead.

#### Notes for AI

- Both columns need content. Each can run to about 300 words. Keep the two roughly balanced unless one is set narrow.
- Each column is a full text editor. Use the text editor sets listed in this catalogue, such as Image, Table, Pull quote, Video or Buttons, where they help the content.
- Put tables, galleries and Two Images in a wide column, because a narrow column is too tight for them.
- The Size setting on sets has no effect inside Text Columns: each set fills its column.
- Use level-three and level-four headings inside a column, never level two.
- Always write a heading, because it labels the block in the editor. Switch on Hide headings when the heading and subheading should not show on the page.
- Turn on Reverse order on mobile only when the right column should be read first on phones.
- When the columns differ in length, use Vertical Align Content to line them up.

### Cards (`cards`)

A row of cards, each with a title, short text, an optional image or icon and an optional button.

Listed under Content in the page builder.

#### When to use

- Several short items of equal weight, such as features, benefits, steps in a process or links to key pages.
- Signposting to other pages, with one button on each card.
- Choose Card Type for the whole block: Text for bordered cards, Image for a photo above each title, Icon for a small icon or logo.

#### When not to use

- One item on its own: use Media and text or Call to action.
- Two pieces of longer text: use Text Columns.
- A set of photos with no text: use Gallery.
- Items that need headings, lists of several points or more than a short paragraph each: use Text Columns or separate Text blocks.

#### Notes for AI

- When the cards would link to entries in a collection, such as posts, projects or team members, look for a block that lists that collection, usually listed under Dynamic in the page builder, and use it instead of Cards. Use Cards for collection entries only when there is a very good reason.
- Use three cards, or six in two rows of three. Two or four cards form two columns, and one card sits alone in the middle.
- Keep every card alike: a title of a few words, and card text of one or two sentences, about 30 words, with no headings.
- Each card shows only its first button, and that button makes the whole card clickable. Give each card one button at most.
- With Card Type set to Image or Icon, every card needs an image. Use the same image shape for all cards in a block.
- Write card titles and text to a similar length, so the cards line up evenly.
